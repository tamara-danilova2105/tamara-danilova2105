## 🌍 Across The World (ATW)

https://acrosstheworld.ru

Коммерческая платформа для туров (SPA + backend + админка + CRM)

- React + TypeScript (Feature-Sliced Design), сложные формы и управление состоянием
- Node.js + MongoDB, REST API и админ-панель
- CRM: управление турами, клиентами и бронированиями
- доменная модель и связи между сущностями (туры, даты, бронирования, клиенты)
- модерация контента и пользовательские workflow

В проекте выстроена инженерная среда:

- релизный процесс: versioning, changelog, git-теги, rollback
- стандартизация разработки: conventional commits, commitlint, husky
- архитектурные решения фиксируются через ADR
- мониторинг ошибок и продакшн-наблюдаемость (Sentry)
- контракт между frontend и backend: типизация API, контроль совместимости и изменений схем
- продуктовая аналитика и UX-наблюдаемость (Microsoft Clarity, анализ поведения пользователей)
